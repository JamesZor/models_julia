1. FULL MEMORY (H=Inf) DOMINATES. Shortening the forgetting half-life strictly hurts growth AND
   drawdown AND reactivity: termW 3.7→0.9, G +0.005→−0.000, maxDD 0.86→0.94, and home w rises
   0.18→0.51 as H shrinks. Forgetting old matches does NOT make the alarm react faster to home's
   badness — it makes it react LESS: a short effective sample makes the EB pool each unit back
   toward the 0.5 prior (react_match: full memory crosses home<0.35 at match 75; short memory
   NEVER does). Reactivity to a PERSISTENT bias comes from ACCUMULATING evidence, not forgetting.
2. NO SMOOTHING (α=1) is best-or-tied. EMA smoothing is the real STABILITY knob — it cuts jitter
   monotonically (0.031→0.010) and gives a beautifully smooth w-path — but it LAGS the persistent
   signal, costing growth as cadence slows (α=0.15,K=8: termW 1.34, home stuck at 0.35). Only
   worth it if you specifically want a calmer w-path; keep cadence frequent if you do.
3. CADENCE barely matters at full memory: termW 2.9–3.9 across K=1..8, maxDD ~0.86 flat. Refit
   anywhere from weekly to 8-weekly. The r01 default (≈5wk, H=Inf, α=1) is already near-optimal.
OPERATING POINT: full memory (H=∞), no EMA (α=1), refit every ~4–6 weeks. Don't tune — the bias
is stable, so the estimator wants all the history and no forgetting.
