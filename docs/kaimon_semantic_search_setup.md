# Setting Up Semantic Search in Kaimon.jl on Arch Linux

This guide walks you through configuring **Kaimon.jl's Semantic Search** feature tailored specifically for your `mcmc-beast` server (Arch Linux, Ryzen 9 5950X with 32 threads, 128GB RAM). By connecting Kaimon.jl to **Ollama** (for generating embeddings) and **Qdrant** (for vector storage), you can index your codebase and enable AI agents like Claude Code to perform Retrieval-Augmented Generation (RAG) directly on your code.

---

## Step 1: Install and Configure Ollama (CPU-only)

Ollama is used to run local embedding models. While this is technically a "CPU-only" execution, your Ryzen 9 5950X (32 threads @ 5.09 GHz) is incredibly powerful and will execute these embedding models with near-GPU speeds.

### 1.1 Install Ollama
On Arch Linux, you can install Ollama directly from the official repositories using `pacman`:
```bash
sudo pacman -Sy ollama
```

### 1.2 Enable and Start the Service
Enable the Ollama service to start on boot, and start it now:
```bash
sudo systemctl enable --now ollama
```
By default, Ollama will run as a background service listening on `http://127.0.0.1:11434`.

### 1.3 Pull an Embedding Model
Since you are on a CPU-only server, we need a small, highly optimized embedding model. `nomic-embed-text` is highly recommended for code and text embeddings.
```bash
ollama pull nomic-embed-text
```

---

## Step 2: Install and Run Qdrant via Docker

Qdrant is a high-performance vector database that Kaimon.jl uses to store and query the embeddings generated by Ollama.

### 2.1 Install Docker
If Docker is not already installed on your Arch Linux server, install it and start the daemon:
```bash
sudo pacman -Sy docker
sudo systemctl enable --now docker
```
*(If you want to run Docker commands without `sudo`, add your user to the `docker` group: `sudo usermod -aG docker $USER` and re-login)*

### 2.2 Run the Qdrant container
We will run Qdrant on its default ports (`6333` for REST API and `6334` for gRPC) and mount a local volume so your indexed codebase embeddings persist across server reboots.

Create a directory for Qdrant storage:
```bash
mkdir -p ~/qdrant_storage
```
Run the Qdrant Docker container:
```bash
docker run -d \
  --name qdrant \
  --restart unless-stopped \
  -p 6333:6333 \
  -p 6334:6334 \
  -v ~/qdrant_storage:/qdrant/storage:z \
  qdrant/qdrant
```
You can verify it is running by checking the API:
```bash
curl http://localhost:6333/
```
*(You should see a JSON response with Qdrant's version info.)*

---

## Step 3: Connect Kaimon.jl and Index Your Codebase

With both Ollama and Qdrant running on their default ports, Kaimon.jl can seamlessly connect to them.

### 3.1 Verify Default Ports
Kaimon.jl is configured by default to look for these services on standard local ports:
*   **Ollama:** `http://localhost:11434`
*   **Qdrant:** `http://localhost:6333`

Since we used the default ports, Kaimon will auto-detect them perfectly.

### 3.2 Indexing via the Kaimon TUI
Kaimon includes a powerful Terminal User Interface (TUI) that allows you to manage sessions and search indexes.

1. **Launch the Kaimon TUI:**
   Start Kaimon in your server terminal (`kaimon`).
2. **Navigate to the 'Search' Tab:**
   Press `4` on your keyboard to navigate to the **Search** tab.
3. **Configure the Index:**
   * Select the **Embedding Model** you pulled earlier (`nomic-embed-text`).
   * Provide the **Target Directory/Path** to your codebase (`/root/BayesianFootball`).
4. **Start Indexing:**
   Trigger the indexing process. Kaimon will now read your source files, chunk them, call Ollama to generate semantic embeddings for each chunk, and store them into Qdrant.
   *(Note: Thanks to the 32 threads on your Ryzen 9 5950X, Ollama will tear through your entire `BayesianFootball` codebase and embed it almost instantly. You can monitor the progress directly in the TUI.)*

---

## Step 4: Using RAG with Claude Code

Once indexing is complete, the semantic search tool is automatically exposed to Claude Code via Kaimon's MCP server.

When you ask Claude Code a question like:
> *"Where is the database connection logic implemented in this codebase?"*

Claude Code will automatically:
1. Formulate a search query.
2. Call Kaimon's `qdrant_search_code` tool.
3. Kaimon will embed the query using Ollama and retrieve the most semantically relevant code chunks from Qdrant.
4. Claude Code will use these specific snippets as context to give you an accurate, grounded answer.
